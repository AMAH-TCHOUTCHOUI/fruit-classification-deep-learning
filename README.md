# Fruit Classification using Deep Learning

This project implements a fruit classification system using deep learning techniques.  
The models are trained on the **Fruits360 dataset** and evaluated using multiple architectures to compare performance.

## Models Implemented

The following deep learning models were implemented and compared:

- Convolutional Neural Network (CNN)
- MobileNetV2 (Transfer Learning)
- MobileNetV2 with Fine-Tuning

These models were implemented using **TensorFlow / Keras**.

## Dataset

The project uses the **Fruits360 dataset**, a dataset containing images of various fruit classes used for image classification tasks.

## Project Workflow

1. Data preprocessing and image normalization
2. Model training using CNN architecture
3. Transfer learning using MobileNetV2
4. Fine-tuning MobileNetV2 to improve performance
5. Model evaluation and comparison

## Technologies Used

- Python
- TensorFlow / Keras
- Google Colab
- Deep Learning (CNN)
- Transfer Learning

## Web Interface

A simple **local HTML interface** was developed to test the trained model and simulate a real-world application scenario.
